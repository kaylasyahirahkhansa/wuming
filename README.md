# wuming

无名。
wú míng.

无欲，万物皆明。
wú yù, wàn wù jiē míng.

而欲无欲，一也。
ér yù wú yù, yī yě.

万物自运，无所为也。
wàn wù zì yùn, wú suǒ wéi yě.

虽为无成，因物自运。
suī wéi wú chéng, yīn wù zì yùn.

人我无别，彼此为一。
rén wǒ wú bié, bǐ cǐ wéi yī.

天地无别，虽二而一。
tiān dì wú bié, suī èr ér yī.

彼此忘矣，如此而已。
bǐ cǐ wàng yǐ, rú cǐ ér yǐ.

复无。
fù wú.
